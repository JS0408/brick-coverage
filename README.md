# 브릭 커버리지 시뮬레이터

초음파(파라메트릭) 스피커 **브릭 / 브릭미니**의 설치 조건을 넣으면, 서 있는 사람의 귀 높이
기준 방송 커버리지를 측면도·후면도·평면도로 그려 주는 한 화면짜리 도구입니다.

👉 **https://js0408.github.io/brick-coverage/**

- `index.html` 한 장이 전부입니다. 의존성·빌드·서버 없음 — 내려받아 브라우저로 열어도 그대로 돕니다.
- 스마트폰에서도 볼 수 있게 되어 있습니다.

## 계산 기준

| 항목 | 값 |
|---|---|
| 브릭 지향각 | 수평 ±10° / 수직 ±3° (−10 dB 기준 반각) |
| 브릭미니 지향각 | 수평 ±7° / 수직 ±3° |
| 유효 도달 거리 | 10 m (발음면에서 잰 직선거리) |
| 브릭 외형 | 220 × 105 × 60 mm |
| 브릭미니 외형 | 128 × 66 × 30 mm |
| 청취 기준면 | 신장 − 0.10 m (기본 1.70 m → 귀 높이 1.60 m) |

빔은 점이 아니라 **발음면 전체**에서 출발해 지향각만큼 벌어지는 것으로 계산하며, 유효 거리
이내에서 **귀 높이 평면과 만나는 영역**을 커버리지로 잡습니다. 바닥 자국이 아니라 귀 높이인
것이 핵심입니다 — 얕은 각도에서는 빔이 머리 위로 지나가 "자국은 있어도 들리는 사람은 없는"
경우가 실제로 흔합니다.

실제 도달 범위는 반사면·암소음·설치 오차에 따라 달라집니다. 현장 설계 시 참고용으로
사용하십시오.
